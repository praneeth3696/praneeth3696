<table>

<td width="50%" valign="top">

**[ClassRoom Code](https://github.com/praneeth3696/ClassRoom-Code)**

Full-stack coding-lab platform for a college department. Teachers publish worksheets, students solve them in an in-browser editor, and answers are auto-graded across C/C++/Java/Python plus SQL and MongoDB engines — with untrusted code sandboxed through Judge0.

`React` `Node.js` `Express` `PostgreSQL` `Judge0` `OAuth`

</td>
<td width="50%" valign="top">

**[ModelAuth](https://github.com/praneeth3696/modelauth)**

Detects silent LLM model substitutions by API providers using statistical change-point detection — with no access to weights, logprobs, or reference data. Flags cross-architecture swaps within ~15 probes at a sub-1% false alarm rate.

`Python` `NumPy` `SciPy` `Ollama` `Chart.js`

</td>
</tr>
<tr>
<td width="50%" valign="top">

**[NetSpecter](https://github.com/praneeth3696/NetSpecter)**

Passive network auditor that catches credentials transmitted in plaintext over HTTP, FTP, and mail protocols. TCP stream reassembly for split-packet payloads, cloud API key detection, and offline PCAP replay for forensics.

`Python` `Scapy` `libpcap` `Rich` `Linux`

</td>
<td width="50%" valign="top">

**[ModeOS](https://github.com/praneeth3696/modeos)**

Terminal-based Linux utility that reconfigures brightness, volume, night light, and running processes from declarative YAML modes. Pluggable hardware backends, graceful process control, and exact state reversion.

`Python` `psutil` `PyYAML` `Docker`

</td>
